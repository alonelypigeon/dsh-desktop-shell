# 性能基线（v1.0.0）

v1.0 的效率验收口径是「**建基线 + 不退化**」：把五项效率改动（启动路径、稳态 I/O、重连探测、托盘重建、包体）的现状量化存档，后续版本对照本文件验收。测量日期 2026-09-11，机器为日常开发用 Windows 11 x64 笔记本（无特殊隔离），构建均为 dev 产物（`tsc` 输出直接由 Electron 加载，非打包版）。

## 冷启动到首帧

**测量方法**：临时入口脚本（未随仓库交付）在 Electron 主进程入口记 `t0`，分别在首个 `BrowserWindow` 的 `ready-to-show`（首帧）与 `did-finish-load` 打点。每个测量点使用**全新** `--user-data-dir` 与临时 `DSH_DESKTOP_CONFIG`（不触碰真实状态、不恢复历史窗口、不自动连接），两版本**交替各 7 轮**以抵消机器状态漂移，取中位数。

| 指标（7 轮中位） | 0.8.1 | 1.0.0 | 差 |
|---|---|---|---|
| `ready-to-show`（首帧） | **291 ms** | **304 ms** | **+13 ms** |
| `did-finish-load` | 276 ms | 297 ms | +21 ms |

原始值（`ready-to-show`，ms）：

- 0.8.1：2272（首轮 OS 缓存冷启动离群点）、285、285、291、296、293、283
- 1.0.0：310、314、304、274、304、312、301

**结论（诚实记录）**：冷启动**没有赢**——v1.0 比基线慢约 13 ms（+4.5%，此前 3 样本的「+25–30 ms」估计偏高，复测钉死为 +13 ms）。原因是启动首帧路径新增了会话恢复计划等模块加载与逻辑。v1.0 的效率收益不在启动，在下面的稳态 I/O 与包体。每轮首轮的 ~2.3 s 离群点是 OS 文件缓存/Defender 首扫，两版本同在第一轮出现，中位数不受影响。

## 稳态 I/O 与运行时

| 项 | 0.8.1 | 1.0.0 |
|---|---|---|
| 共享配置兜底轮询 | 5 s 定时重读 | `fs.watch` 为主通道，60 s 仅兜底 |
| `shell-state.json` 写路径 | 每次读-改-写全文件 | 内存态持有 + `writeShellState` 直写 |
| 重连探测 | 3 s 间隔 vs 5 s 超时**互相重叠** | 2.5 s 超时 + in-flight 去重，不叠加 |
| 托盘菜单 | 每次 SPA 导航都可能整棵重建 `Menu` | 按状态签名缓存，签名不变不重建 |
| 后台窗口网络 | `backgroundThrottling` 默认开（隐藏即被节流） | 内容视图关闭节流（D2），隐藏时网络照常 |

## 包体（Windows 双产物）

| 产物 | 0.5.0（上一打包基线） | 1.0.0 | 变化 |
|---|---|---|---|
| NSIS Setup | 95.43 MB | **87.50 MB** | −7.93 MB（−8.3%） |
| Portable | 85.86 MB | 87.28 MB | +1.42 MB（原因未查明，见下） |
| win-unpacked | 349.76 MB | **304.27 MB** | −45.5 MB（−13.0%） |
| `locales/` | 55 个 / 46.65 MB | **2 个 / 1.09 MB** | −45.6 MB |
| 文件数 | 75 | 23 | −52 |

手段：`electronLanguages: [en-US, zh-CN]`（只保留两种语言包）与打包排除 `dist/**/*.map`。语言包回收体现在 win-unpacked 与 NSIS 上；**portable 反增 1.42 MB 的原因尚未查明**（portable 是自解压重构，理论应同样受益），留待后续排查。

## 复现

1. 构建：`npm run build`（两版本各自工作树）。
2. 打点入口：临时脚本 `electron <脚本> <dist/main.js>`，脚本内记 `t0`、监听 `browser-window-created` 的 `ready-to-show` / `did-finish-load`、15 s 后 `app.exit(0)`。
3. 隔离：每次运行追加 `--user-data-dir=<全新临时目录>`（Electron 认该 Chromium 开关）并设临时 `DSH_DESKTOP_CONFIG`、清空 `DSH_URL`。
4. 两版本交替 ≥5 轮，取中位数；首轮离群点靠中位数天然剔除。
